# OS1 yin-yang app icon (Icon Composer)

Black/pearl yin-yang squircle icon for the OS1 Mac app, built as an editable
Apple **Icon Composer** document so specular highlights, translucency and
shadows come from the real Liquid Glass renderer instead of painted bevels.

## The icon

**`OS1Meridian.icon`** — pure vertical seam, chosen from four explored
orientations (reference tilt 12°, vertical, horizontal, diagonal 30°) as the
cleanest mark and the most legible at 16 px.

- `previews/os1-meridian.png` — 1024 px render (full-bleed)
- `previews/small/` — 16/32 px legibility checks
- `os1-meridian.icns` + `icon-512-padded.png` — legacy fallbacks, rebuilt by
  `./build-fallbacks.sh` (renders every slot through `ictool`, then `pad.swift`
  centers the art at **824/1024 of the canvas** — ictool exports are full-bleed,
  and an unpadded icns/dock PNG draws visibly oversized next to other Dock
  icons). Source iconset in `fallback-os1-meridian.iconset/`.

Only the sources are tracked (`generate.ts`, `pad.swift`,
`build-fallbacks.sh`, the `.icon` package); the rendered artifacts above —
`previews/`, the `.icns`, `icon-512-padded.png`, the iconset — are gitignored
and rebuilt with the commands below.

The `.icon` package holds `icon.json` + one SVG layer in a single
`mode: "combined"` glass group (`specular: true`, translucency 0.3) — one
unified glass object, no per-lobe inflation.

## Geometry / how to tweak

Everything is generated by `generate.ts` (run `bun run generate.ts`, then
re-render). The seam keeps true yin-yang structure — tangential edge meetings,
inflection through the canvas center, two symmetric interlocking heads — with
two tuning knobs at the top of the script:

- `BULGE` (currently **0.6**): head depth. `1` = classic half-circle seam,
  which reads bulbous/"over the top" on a squircle; lower is subtler.
- `V` (currently **180**): angles the center-inflection tangent. With a
  sub-classic bulge a horizontal center tangent (the classic construction)
  reads as a pinched kink; `V` restores a smooth flowing S.

`seamFor()` accepts any rotation angle, so dropped orientations are one line
away if ever wanted again.

Optical depth is baked *softly* into the SVG (radial smoke/pearl gradients, a
`feGaussianBlur` seam shadow clipped to the pearl lobe, a thin lit seam edge,
an Aqua top sheen) — no thick bevels; Icon Composer's glass does the rest.

## Rendering

```sh
ICTOOL="/Applications/Icon Composer.app/Contents/Executables/ictool"
"$ICTOOL" OS1Meridian.icon --export-image --output-file out.png \
  --platform macOS --rendition Default --width 1024 --height 1024 --scale 1
```

Gotchas learned along the way (kept for future edits):

- `ictool` accepts `"mode": "combined"` and `"specular": true`, but rejects
  `"blur-material"` keys in `icon.json`.
- `feGaussianBlur` filters and `clipPath` **are** supported in layer SVGs —
  use them instead of multi-stroke fake blurs (those band visibly).
- Separate glass groups per color half make the top half look like a raised
  inflatable slab — keep everything in one combined group.
